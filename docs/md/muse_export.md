## muse_export

**Description:** MUSE = Modelling of Uncertainty as a Support of Environment; Export tool

### Usage

```bash
muse_export [OPTIONS]
```

### Options

#### `-m`, `--geom`
**Type:** Value (flag)
**Description:** Geometry model

geometry model

#### `-l`, `--label`
**Type:** Value (flag)
**Description:** Label

label

#### `-s`, `--sis`
**Type:** Value (flag)
**Description:** Sis simulation

sis simulation

#### `-r`, `--nrows`
**Type:** Value (flag)
**Description:** Raster number of rows

Number of raster number of rows

#### `-c`, `--ncols`
**Type:** Value (flag)
**Description:** Raster number of cols

Number of raster number of cols

#### `-x`, `--min_x`
**Type:** Value (flag)
**Description:** Raster min x

raster min x

#### `-y`, `--min_y`
**Type:** Value (flag)
**Description:** Raster min y

raster min y

#### `-X`, `--max_x`
**Type:** Value (flag)
**Description:** Raster max x

raster max x

#### `-Y`, `--max_y`
**Type:** Value (flag)
**Description:** Raster max y

raster max y

#### `-o`, `--out`
**Type:** Value (flag)
**Description:** Output file

Path to output file
