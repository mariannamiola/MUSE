# MUSE — muse_export

Export the computed results (statistics and simulations) to CSV or GeoPackage,
optionally appending to an existing table.

## Command-line reference

The complete, always up-to-date reference for every option of `muse_export` is
generated from the source code and available at:

- Markdown: ../../docs/md/muse_export.md
- HTML:     ../../docs/html/muse_export.html

or directly from the tool:

    muse_export --help

There is also a raster-oriented variant, `muse_export_raster`, documented at
../../docs/md/muse_export_raster.md.

## Runnable examples

End-to-end workflows are provided under ../../examples (see ../../examples/README.md).
