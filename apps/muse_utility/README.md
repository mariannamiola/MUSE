# MUSE — muse_utility

Auxiliary utilities: recursive file listing and navigation of the JSON
processing-history (workflow provenance / metadata).

## Command-line reference

The complete, always up-to-date reference for every option of `muse_utility` is
generated from the source code and available at:

- Markdown: ../../docs/md/muse_utility.md
- HTML:     ../../docs/html/muse_utility.html

or directly from the tool:

    muse_utility --help

## Runnable examples

End-to-end workflows are provided under ../../examples (see ../../examples/README.md).
