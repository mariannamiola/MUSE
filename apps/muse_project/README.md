# MUSE — muse_project

Create and initialize a MUSE project: the hierarchical folder structure (in/out)
and the project metadata (JSON).

## Command-line reference

The complete, always up-to-date reference for every option of `muse_project` is
generated from the source code and available at:

- Markdown: ../../docs/md/muse_project.md
- HTML:     ../../docs/html/muse_project.html

or directly from the tool:

    muse_project --help

## Runnable examples

End-to-end workflows that use `muse_project` are provided under ../../examples
