# MUSE — muse_plot

Produce diagnostic plots from project data: histogram, bivariate, error and
triangular (ternary) plots.

## Command-line reference

The complete, always up-to-date reference for every option of `muse_plot` is
generated from the source code and available at:

- Markdown: ../../docs/md/muse_plot.md
- HTML:     ../../docs/html/muse_plot.html

or directly from the tool:

    muse_plot --help

## Runnable examples

End-to-end workflows are provided under ../../examples (see ../../examples/README.md).
