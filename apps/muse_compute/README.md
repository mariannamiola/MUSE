# MUSE — muse_compute

Run the geostatistical computations on the target geometry: conditional simulation
(Sequential Gaussian Simulation, Sequential Indicator Simulation), summary statistics,
and back-transform of the results to the original variable space.

## Command-line reference

The complete, always up-to-date reference for every option of `muse_compute` is
generated from the source code and available at:

- Markdown: ../../docs/md/muse_compute.md
- HTML:     ../../docs/html/muse_compute.html

or directly from the tool:

    muse_compute --help

End-to-end workflows that use `muse_compute` are provided under ../../examples
